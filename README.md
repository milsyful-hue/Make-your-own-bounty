Entry for make.fun's "Promote make.fun's make-your-own-bounty post on X" bounty: one public X post by @Udachii quoting make.fun's make-your-own-bounty post, with a photo of its own attached, @makefunai and play code makefun-mill-parcel-mango in its text. This repository hands in the post's address in POST.json; main.ts reads POST.json and writes a deterministic report about the post to the output directory. The post itself is the entry: places go by its replies plus reposts plus quotes, the highest first, and the top 50 share $250.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
